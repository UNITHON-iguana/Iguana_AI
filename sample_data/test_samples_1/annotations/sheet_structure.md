# BS.xlsm 엑셀 시트 구조 및 도메인 필드 매핑 명세

이 문서는 실제 현장 사무 담당자가 작성한 `BS.xlsm` 엑셀 파일의 시트별 구조와 "현장노트 AI" 도메인 엔티티 간의 매핑을 정의합니다.

---

## 1. 프로젝트 기본 정보
- **공사명 (Project Title)**: `침산 포스코 더샵 프리미엘`
- **시트 목록**:
  1. `사진대지` (사진별 상세 기록 및 사진대지 서식)
  2. `집계표` (일일작업현황 일자별/구분별 집계)
  3. `누계` (기성누적집계)

---

## 2. `사진대지` 시트 구조 및 매핑

`사진대지` 시트는 **11개 행(Row)**이 하나의 **사진대지 블록(Record)**을 구성합니다. (예: Row 2~12, Row 13~23, ...)

| 엑셀 위치 | 엑셀 라벨 | 예시 데이터 | 현장노트 AI 도메인 필드 | 필드 타입 | 설명 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Col 1 (또는 Col 3)** | 사진 No. | `378` | `photo_no` | Integer | 사진 일련번호 |
| **Col 4** | 라벨 | `구    분` | - | - | 항목명 라벨 |
| **Col 5** | 구분값 | `금속관벽체` | `process_category` / `work_item` | String | 공종 및 세부 구분 |
| **Col 6** | 라벨 | `작업내용` | - | - | 항목명 라벨 |
| **Col 7** | 규격/치수 | `65` | `material_spec` / `work_description` | String/Number | 관경(65A 등) 및 규격 |
| **Col 8** | 수량 | `1` 또는 `2` | `quantity` | Number | 확인/시공 수량 |
| **Row +9, Col 4** | 라벨 | `위     치` | - | - | 항목명 라벨 |
| **Row +9, Col 7** | 위치값 | `3동 1.2세대 38층` | `location` (동·층·구역) | String | 시공 구역 및 세대 위치 |
| **Col 17~18** | 소계/분류 | `금속관벽체65` / `1` | `aggregated_item` | String/Number | 구분+규격 합성 집계키 |

---

## 3. `집계표` (일일작업현황) 시트 구조

- **역할**: 일자별/공종구분별 시공 수량 매트릭스 집계.
- **행(Rows)**: 세부 공종 및 규격 항목 (예: `금속관입상차열15` ~ `125`, `금속관벽체15` ~ `65`, `세대스프링클러` 등 총 159개 항목).
- **열(Cols)**: 작업 일자 (예: `2024-06-29` 등)별 일일 작업량.
- **도메인 연결**: `PlanProcess` 및 `PhotoRecord`의 일별 검수 완료 수량 집계 기준.

---

## 4. `누계` (기성누적집계) 시트 구조

- **역할**: 프로젝트 시작일부터 현재까지의 공종별 누적 기성 집계.
- **주요 컬럼**: `구분(항목명)`, `작업일(누적 일수)`, `수량(기성 실적)`, `누계`.
- **도메인 연결**: `계획 대비 공정/자재 비교` 화면 및 기성 보고서 내보내기 데이터.

---

## 5. 생성된 구조화 변환 파일
에이전트와 백엔드 코드가 즉시 읽고 파싱할 수 있도록 아래 JSON/CSV 파일이 추출되어 있습니다:
- `BS_photo_daeji.json` & `BS_photo_daeji.csv`: 510개 블록 (유효 사진대지 데이터 32건 포함)
- `BS_daily_summary.json`: 159개 일일 집계 항목
- `BS_cumulative.json`: 105개 기성 누계 항목
