# DG2.xlsm 엑셀 시트 구조 및 도메인 필드 매핑 명세

이 문서는 실제 현장 사무 담당자가 작성한 `DG2.xlsm` 엑셀 파일의 시트별 구조와 "현장노트 AI" 도메인 엔티티 간의 매핑을 정의합니다.

---

## 1. 프로젝트 기본 정보
- **공사명 (Project Title)**: `영종도 인스파이어 복합리조트`
- **시트 목록**:
  1. `사진대지` (사진별 상세 기록 및 사진대지 서식)
  2. `집계표` (일일작업현황 일자별/구분별 집계)
  3. `누계` (기성누적집계)

---

## 2. `사진대지` 시트 구조 및 매핑

`사진대지` 시트는 **11개 행(Row)**이 하나의 **사진대지 블록(Record)**을 구성합니다. (예: Row 2~12, Row 13~23, ...)
단일 사진대지 블록 내에 최대 3개 품목 라인(Row +0, Row +3, Row +6)이 복합 기재될 수 있습니다.

| 엑셀 위치 | 엑셀 라벨 | 예시 데이터 | 현장노트 AI 도메인 필드 | 필드 타입 | 설명 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Col 1** | 사진 No. | `801` | `photo_no` | Integer | 사진 일련번호 |
| **Row +0, Col 5** | 구분값 1 | `금속관벽체` / `보온덕트벽체` | `category` / `work_item` | String | 제1공종 및 세부 구분 |
| **Row +0, Col 7** | 규격 1 | `50` / `1500*900` | `spec` | String/Number | 제1규격/치수 |
| **Row +0, Col 8** | 수량 1 | `0.5` / `1` | `quantity` | Number | 제1시공 수량 |
| **Row +3, Col 5** | 구분값 2 | `차열재마감` | `category` | String | 제2공종 (선택) |
| **Row +3, Col 7~8** | 규격/수량 2 | `1500*900` / `1` | `spec` / `quantity` | String/Number | 제2규격/수량 |
| **Row +6, Col 5** | 구분값 3 | `무보온덕트벽체` | `category` | String | 제3공종 (선택) |
| **Row +9, Col 7** | 위치값 | `리테일 3층`, `리테일 4층` | `location` | String | 시공 구역 및 위치 |
| **Col 26** | 날짜 | `2023-09-03` | `work_date` | Date/String | 시공 일자 |

---

## 3. `집계표` 및 `누계` 시트 구조

- **집계표 (일일작업현황)**: 일자별/공종구분별 시공 수량 매트릭스 집계.
- **누계 (기성누적집계)**: 프로젝트 시작일부터 현재까지의 공종별 누적 기성 집계.
- **도메인 연결**: `PlanProcess` 및 `PhotoRecord`의 일별 검수 완료 수량 집계 기준.
